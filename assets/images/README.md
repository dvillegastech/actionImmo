# Logo

Coloca aquí el logo de Action Immobiliaria (logo.png) para que aparezca en el splash screen.

Requisitos:
- Formato: PNG con fondo transparente
- Tamaño recomendado: 512x512 px
- Nombre del archivo: `logo.png`

Para generar el splash screen después de agregar el logo, ejecuta:
```bash
dart run flutter_native_splash:create
```
